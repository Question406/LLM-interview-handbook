微软研究 / SLM / 端侧岗会把 Phi 当默认叙事。公开论文链是 Phi-1「教科书数据」、Orca 用 GPT-4 解释轨迹做 imitation（`2306.02707` 对应 Orca，不是 Phi）、Phi-3 把小模型推到手机可跑。评委听过太多「我们数据很好」，要你能讲 **质量是一条可操作的轴**，以及它在什么时候失效。

## 质量是缩放轴，不是口号

Chinchilla 说的是：给定计算，token 数和参数量要匹配。Phi 加了一维：**同样 token 数，分布的信息密度可以差一个数量级**。网页重复、模板、错代码，模型先学的是噪声统计；「教科书」式数据是逐步讲解、自洽、覆盖基础算法的文本。Phi-1 用约 $7\mathrm{B}$ 高质量 token 训 $1.3\mathrm{B}$，代码基准上打过用大得多语料训的同级模型。这不是否定规模，是说脏数据的有效计算被浪费了。

我会把数据工作说成可复现的 pipeline，而不是「我们请了专家写教材」：

1. **过滤。** 分类器打质量分，扔模板、重复、有害、明显错的代码。过滤本身会引入偏差，要留一份未过滤对照，看基准涨的是能力还是风格。
2. **合成。** 用更大模型写习题、教科书章节、带中间步骤的证明。合成能补长尾，也会复制教师的幻觉和基准泄漏。
3. **课程。** 先基础后难题。Orca 的 progressive 就是：ChatGPT 轨迹当垫步，再上 GPT-4 的复杂解释，避免小模型一次性吞不下教师分布。

Orca 的核心警告很适合开口：只模仿 GPT-4 的 **最终答案风格**，小模型会在聊天基准上虚高，在复杂推理任务上仍然会失败。要学的是 explanation traces。这和「堆参数」正交：13B 的 Orca 靠轨迹质量逼近更大 chat 模型的部分推理，不是靠把层数加到 70B。

Phi-3-mini（$3.8\mathrm{B}$）公开叙事仍是：过滤网文 + 合成，长上下文，端侧可部署。面试用它举例时，报的是「小模型 + 数据配方」，不要把 MMLU 分数当成已赢过 GPT-4。

## 面试怎么讲「不是只堆参数」，同时别讲满

我会三句话收：

1. **参数量吸收的是有效信息。** 同样 FLOPs，高质量数据让每 step 的梯度更指向可泛化规则。这是数据轴，不是魔法架构。
2. **小模型的产品位是延迟、成本和端侧，不是替代前沿。** Copilot 补全、手机上的 Phi、Azure 里的 mini 部署，用的就是这条。限流和降级见 `msft-azure-tpm`。
3. **规模仍买三样东西：** 世界知识覆盖、长尾任务、对抗鲁棒。教科书覆盖不了今年的内部 API；多跳仓库问答、含糊的企业政策，还是更大模型或 检索增强生成（RAG）。Phi 路线改善的是能力与成本的取舍，规模仍然有价值。

评委常攻的点是污染。小模型在公开基准上「打过 70B」，要能回答：训练数据有没有做过 n-gram / embedding 去污，合成教师是否见过测试题，有没有留一块时间切片的私有评测。答「我们过滤了」不够；要说过滤目标和泄漏指标。微软自己在 Orca 里也强调：浅模仿会在聊天式评测上过估。

和 ORPO 的衔接：Phi-2 出现在 ORPO 论文的实验里，小模型对齐更在乎 **少加载一个参考模型**。数据质量故事和对齐故事不要合成一句「Phi 全都靠 ORPO」。见 `msft-orpo`。

白板若被追「那数据从哪来」，我会画两条预算：采集/过滤算力和教师合成算力。合成看起来「数据免费」，其实把大模型的推理账单搬到了数据阶段；单位学生参数变便宜，总账不一定便宜。Phi 关注每个 token 提供多少有效信息。

缩放定律别讲成「小模型违反了 scaling」。Chinchilla 管计算、参数、token 数量；Phi 加的是 token 质量。脏网页的有效 $N$ 远小于 token 计数，所以 $1.3\mathrm{B}$ 配 $7\mathrm{B}$ 高密度 token 可以打过更大脏语料模型。这仍是 scaling，只是把无效 token 从分母拿掉了。产品上 Phi 适合端侧和辅助模型：Copilot 里小模型做补全/分类、大模型做难推理，中间用 `msft-azure-tpm` 那套降级。

## 追问

- **合成数据会不会把教师的错写进学生？** 会。要有校验器（执行代码、检索事实）或人抽查。无校验的合成等于蒸馏幻觉。
- **为什么不把同样数据喂给 70B？** 可以，而且往往更好。Phi 的主张是单位参数的回报；不是「大数据只配小模型」。算力够时质量和规模该一起加。
- **端侧和云上的分界？** 端侧吃延迟、隐私、离线；云上吃工具和长上下文。Phi 适合端侧和辅助模型，不适合当唯一的企业推理引擎。
- **和「只是蒸馏 GPT-4」的指控？** 蒸馏是手段之一。Phi-1 还有人类/过滤的教科书语料；Orca 明确要轨迹不是答案。承认教师上限：学生很难稳定超过教师的知识截止和事实校准。
