OpenAI / Meta / Google 评测岗会问「MMLU 涨了是能力还是背题」。GPT-3 论文就用 n-gram 去污染；后来发现只去题面不够，答案和解析博客一样能泄漏。对齐岗问这题，是因为 基于人类反馈的强化学习（RLHF） / 监督微调（SFT） 数据、合成轨迹、红队集都可能把评测吞进去，安全数字和能力数字会一起假。别停在「我们做过 embedding 去重」。

## 污染长什么样，别只查全文哈希

训练里更常见的是：网页镜像、教材 PDF、GitHub 上的题解、评测博客、把 GSM8K 写进 instruction 数据。Exact hash 只能抓原样拷贝。分层：

1. **规范化 exact。** 去空白、大小写、标点后再哈希。代码还要规范化。
2. **n-gram / MinHash。** GPT-3 用 13-gram 重叠当候选。题短时阈值要按长度调，否则误杀或漏杀。局部改写、挖空填空走这里。
3. **搜索查重。** 把题面当 query 搜训练索引或外网。能抓住「训练没存题面、但存了几乎同样的博客」。对齐数据往往是对话，n-gram 对题面失效时，搜索更有用。
4. **答案 / 解析指纹。** 只吃到解答也算污染。数学最终答案、选择题选项、标准输出、思维链模板都要建索引。
5. **生成式探针。** 给题目前缀看会不会续出原题或原答案。成功加嫌疑；失败不能证明干净。

语义近邻是辅助，不能当自动删除：同主题不同数字的题会误杀，能力评估被压低。命中要进隔离桶人工复核，记下是哪个源、哪次抓取带进来的。

对齐特有的污染：把 XSTest、HarmBench、公开 jailbreak 写进拒答 SFT，再在同一套上报表。看起来 ASR 为 0，其实是背评测，见 `align-red-team`。合成数据自我蒸馏也会把评测格式洗进训练，叫自污染，门禁不同，但查重工具可以共用。

## 实验怎么报，才算做过检测

对照至少三列：公开榜、去掉重叠后的分数、私有变体或时间切分（评测发布日之后的题）。公开榜远高于私有变体，优先怀疑泄漏。报告 n-gram 命中率、只答案重叠占比、源站，不要只说「做过 decontamination」。

Canary 字符串埋进私有集，训练后探测 canary，能抓「整包被复制」这类粗泄漏，抓不住改写。动态换皮能降低背题收益，但不能替代静态检测：旧重叠还在训练集里，只是你换了题看不见了。

面试别吹「我们 n-gram 阈值是 13」。要说清：对选择题、代码、对话各自用什么指纹，误杀怎么复核，公私榜差多少才触发调查。

## 泄漏后怎么办

顺序要说得出，不然像没处理过事故：

1. **隔离。** 命中的训练源进隔离桶，停止用它继续训。不要默默删了却不留审计。
2. **重报。** 在去污染后的训练快照上重跑，或至少报「去掉重叠题后的分数」。旧公开榜标成 contaminated，不要当 SOTA 宣传。
3. **换评测。** 高风险榜准备私有变体：改数字、改选项顺序、改包装语言。安全评测尤其要换，因为拒答示范很容易背题。
4. **查下游。** SFT / 奖励模型（RM） / 强化学习（RL） 数据是否从同一抓取进来。只洗预训练、不洗偏好数据，污染还在。
5. **产品。** 若线上模型已训完，评估用私有集重新定级，该降的能力声明要降。不要靠 输入提示（prompt） 说「请不要背题」。

发现污染还继续报旧榜，是评测诚信问题，比漏检更严重。

## 追问

- **n-gram 和搜索哪个够？** 都不够单独用。n-gram 抓局部重叠；搜索抓改写和题解页。答案指纹是第三层。
- **语义近邻全删行吗？** 不行。题意近但答案不同的要人核。误杀压低能力，漏杀抬高榜。
- **泄漏后能不能「再训一遍忘掉」？** 不可靠。先隔离源、重报、换评测。遗忘不是默认修复。
- **和红队过拟合是一回事吗？** 都是评测失效。污染是训练看见了题；过拟合评测是对着评测分布训练。处理都是隔离 + held-out。
