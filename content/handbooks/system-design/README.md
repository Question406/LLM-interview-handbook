## 建议练习顺序

1. 第一天：答题流程、容量估算、接口模型，再完整设计短链。不要先背中间件名。
2. 第二天：缓存、分片、事务与队列，练聊天和预约支付，重点检查响应丢失后的重试。
3. 第三天：过载、容灾、发布，练任务调度、Feed、文件和通知中的两题。
4. MLE方向：推荐→特征平台→审核→训练发布，画出数据、训练、在线服务与反馈闭环。
5. LLM方向：RAG→推理→Agent→评测，补权限、KV、取消、成本与可验证的成功条件。
6. 按公司选题，用45分钟完成一次口述与白板。先隐藏参考讨论，结束后写下两处最重要的遗漏再补基础。

每次作答都应能走通一个正常请求和一个失败/重试场景。说明至少两项与具体约束相关的取舍，给出监控和验证办法；图中的箭头不是跨服务事务保证。
