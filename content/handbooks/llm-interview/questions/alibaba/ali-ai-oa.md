<div class="quick"><div class="mini-title">30 秒回答</div><p>选择覆盖 Transformer/Agent/MCP + CS 基础；编程仍是算法；Prompt 题要写清角色、提取字段、逐步规则、只输出约定 JSON，并用边界 case 自测。</p></div>
          <div class="full-answer"><div class="mini-title">完整答案</div><p>0325 AI 研发场公开复盘结构：约 20 选择 + 3 编程 + 1 Prompt。</p>
<p>选择侧曾出现：teacher forcing、MHA/MQA/GQA、ReAct、MCP tool vs resource、多 Agent 等。</p>
<p>Prompt 题策略：</p>
<ul>
<li>角色 + 信息抽取默认值；</li>
<li>计费/业务规则逐步写死；</li>
<li>夜间加价等边界单独强调；</li>
<li>强制 JSON schema 输出；</li>
<li>用反例（不足 1km、等候不足 5 分钟）自测。</li>
</ul>
<p>建议同步刷牛客 Prompt 题库。</p></div>
