<div class="quick"><div class="mini-title">30 秒回答</div><p>重点是 Reasoning RL、Agent RL、复杂环境交互、Harness、Tool/Skill routing、Memory、Context Engineering、Agent Eval 和 RL systems；基础模型岗位仍要扎实架构与训练系统。</p></div>
          <div class="full-answer"><div class="mini-title">完整答案</div><p>公开招聘方向已经明确覆盖强化学习、复杂 Agent/环境交互相关能力。面试准备上不要把 Agent 理解成“会 LangGraph”：真实公开面经已经问到 Harness Engineering、Skill vs Tool、context compression、eval coverage 和 Agent self-evolution。</p><p>建议能从一个 Agent failure 一路拆到：model error / tool design / context / memory / harness / reward / training data / eval coverage，并给 controlled ablation，而不是每个问题都回答“换更强模型”。</p></div>
