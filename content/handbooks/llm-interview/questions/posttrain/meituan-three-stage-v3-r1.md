## 真题记录

- 公司：美团
- 团队 / 岗位：大模型算法
- 届别 / 流程：秋招；二面
- 来源类型与可信度：牛客候选人原帖，A
- 原始措辞：**“Post-Training 的工作机制，为什么要做三阶段训练？什么情况下应该用GRPO？为什么DeepSeek用了GRPO？如何从V3到R1？”**

做三阶段，是因为有三种失败、要用三种监督：格式不会；对错能验证但示范不够；开放偏好没法写成 checker。它不是玄学编号，也没有「SFT 之后必须再接两段才算完整」的规矩。把 V3 / R1 这种发布名当成算法名来背，面试官下一问「缺 verifier 怎么办」就答不上了。原帖四问可以串成一条线：后训练按失败模式选监督；有 checker、能成组采样才上 GRPO；DeepSeek 用规则奖励扩大推理规模，省掉了过程奖励模型（RM）；V3 先把基座稳住，R1 再冲 reasoning 强化学习（RL）。

先说三种监督各管什么。示范监督，也就是监督微调（SFT）/ 冷启动，解决格式、工具协议和可读的长推理过程。没有这一段，RL 采出来的轨迹常常解析不了，奖励全是噪声：checker 读不到答案，工具调用对不上字段和类型规范（schema）。冷启动是给后面的 RL 准备一个能进验证器（verifier）的分布，用不着当成又一次普通 SFT。可验证 RL（GRPO / 基于可验证奖励的强化学习（RLVR））在有 checker 时用组内相对优势冲正确率，数学、代码、字段校验都适合，目标是「对」，「像示范」不重要。偏好对齐，用直接偏好优化（DPO）或 RM+PPO，补开放性的文采、安全和拒绝；这些没有唯一正确答案，硬套规则奖励会学出拒答或套话。

三段可以裁剪。没有 verifier，就别为了凑编号硬上一段 RL；开放域没有成对的偏好，DPO 也无从下手。顺序通常是先让输出能解析，再冲可验证的正确率，最后用偏好修风格和安全。倒过来做，要么奖励打在乱格式上，要么拿偏好对去学本该用 checker 判的对错。业务缺哪类信号，就停在对应的阶段，别为了「像 R1」凑满三段。

再说什么时候用 GRPO。条件是奖励能自动复核、同一个输入提示能采出对错混合的组、又想省掉一张和 actor 同规模的价值评估模型（critic）。它解决的是显存和 baseline 的问题，「比 PPO 新所以更好」这个理由站不住。需要逐步价值估计、奖励稀疏又没法成组，或者已经有稳定的 RM+critic 基建，PPO 仍然更合适。DeepSeek 的路线用规则奖励扩大推理规模，避免先训一张容易被 hack 的过程 RM：过程分一旦被套话骗过，后面的 RL 会把错误过程放大。组内相对优势在可验证任务上足够形成对比，正好对上「有 checker、要大规模 rollout」这个约束。

GRPO 也有结构上的缺陷：组内全对或全错就是零梯度，要靠动态采样、过滤空组或者课程来补，换一个发布名解决不了。另外 reward hacking（套格式骗过校验）比 PPO 更依赖 verifier 的质量，这点我会主动讲出来。

最后是 V3 到 R1。V3 偏向稳定的 MoE 基座和通用训练，先有一个能训、能推、格式不崩的底盘，推理能力是「会一点」，并没有靠大规模规则 RL 去堆。R1 偏向在可验证任务上做大规模 reasoning RL，把长程推理从示范分布推进到规则奖励能规模化的区域。监督信号从示范换成了可验证的结果，这才是变强的原因，跟改个名字没关系。R1-Zero 可以拿来讨论「几乎不靠 SFT」，那是实验路线，业务上照样要做格式监督。

所以业务里缺 verifier、采不出混合组时，别照抄 R1 的编号，先补 SFT 冷启动或者规则引擎，再谈 GRPO。把 V3 说成「普通 SFT」、把 R1 说成「换了 GRPO」都太浅，要落到各自解决的失败上：一个是稳定可训的底座，一个是可验证推理的规模化。

## 追问

**可以只做两阶段吗？**
可以。开放客服常常是 SFT+DPO，竞赛数学常常是冷启动+RLVR，第三段只在出现对应失败时才加。硬凑满三段，要么白费，要么引入错误的监督。

**为什么不先 RL 再 SFT？**
格式还没立住时奖励解析不了，RL 会把乱码强化下去。冷启动就是为了让采样轨迹（rollout）能进 checker。R1-Zero 用可读性约束补了一部分格式，业务上还是先 SFT 更稳妥。

**DeepSeek 为什么不用过程 RM？**
过程 RM 容易被套话 hack，而且得先标过程。规则奖励能审计、能规模化，这和选 GRPO+verifier 是同一个逻辑。

**GRPO 和 PPO 怎么选？**
有 critic 基建、要价值估计就用 PPO；能验证、想省 critic、能成组采样就用 GRPO。没有 checker 时，别为了省 critic 硬上 GRPO。
