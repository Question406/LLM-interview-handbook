## 真题记录

- 公司：字节跳动
- 岗位：大模型算法
- 来源类型与可信度：牛客候选人原帖，B
- 原始措辞：**“为什么全好或者全坏，那这一步就对模型训练不起作用”**

这块容易答成「全对说明已经学会、不用更新」或「全错说明题太难、梯度会乱」。原因是组内相对优势的定义：奖励全相同则分子为 0、标准差为 0，优势全为 0，clipped surrogate 对 $\theta$ 没有任务信号。这是 GRPO 用组统计代替 critic 的直接代价，不是实现 bug。我会把这句话接到「数据难度和采样策略」，不停在「除以标准差」。

## 1. 公式：常数奖励上相对优势塌缩

设同 prompt 一组奖励 $r_1,\ldots,r_G$。GRPO 常用

$$
\hat{A}_i=\frac{r_i-\mathrm{mean}(r)}{\mathrm{std}(r)+\epsilon}.
$$

全对或全错时 $r_i\equiv c$，于是 $\mathrm{mean}=c$、分子为 0。即使加上防除零的 $\epsilon$，分子仍是 0，$\hat{A}_i=0$，并不是「很小的噪声梯度」。重要性比 $\rho_i=\pi_\theta(y_i\mid x)/\pi_{\mathrm{old}}(y_i\mid x)$ 无论取何值，

$$
\min\big(\rho_i\hat{A}_i,\ \mathrm{clip}(\rho_i,1-\varepsilon,1+\varepsilon)\hat{A}_i\big)=0.
$$

若损失里还留着相对 $\pi_{\mathrm{ref}}$ 的 KL，这一批最多把政策往锚点拉，并不携带「这道题该怎么做对 / 不该怎么做错」的信息。PPO 的 critic 在这种情况下仍可能给出非零 $A$，只是不一定对；GRPO 没有这张网，零方差就是零更新。RLOO 用留一均值当 baseline，全同组里留一均值仍等于 $c$，同样救不了。

不要把 $\mathrm{std}=0$ 说成「会 NaN 所以训练坏了」。工程上通常有 $\epsilon$，现象是静默空转：吞吐还在、loss 看起来平静、任务没有学到任何东西。

## 2. 工程含义：过易、过难、过训都会制造全同组

组采样的价值是「同题对错混合」。准确率长期为 $0$ 或 $1$ 的 prompt，rollout 成本全部浪费。更麻烦的是动态变化：训练前期有方差的题，后期全部做对，$\sigma$ 再次塌缩，这就是 GRPO 后期收益衰减的常见来源之一。另一侧是 verifier 过严，格式稍差就判零，把本有部分正确的组打成全错。

$G$ 太小也会人为制造全同：真实 pass 率 20% 时，$G=4$ 很容易抽到全错。温度过低、解码过贪心，组内回复字面几乎一样，奖励自然也一样。失败时最常见的错误操作是加大学习率「硬推」：没有方向可推，只会放大数值噪声和 KL 项。

因此监控不能只看平均 reward。平均 reward 接近 0 或 1 时，要拆有效组比例、组内 $\sigma$、pass@k 与 pass@1 的缺口。缺口还在、组内 $\sigma$ 却是 0，说明采样预算不够，而不是模型已经饱和。

## 3. 怎么恢复有效信号，以及方法何时失败

常用手段对应不同病因：

- **过滤**：丢掉 accuracy $\in\{0,1\}$ 的组，DAPO 的动态采样就是这条，保证进反向传播的 batch 都有相对信号；
- **课程**：提高题难或换还没饱和的 prompt 池，让组内重新出现对错混合；过难则反向降难度，先保证偶然能做对；
- **探索**：增大 $G$、略抬温度或 top-p，提高至少一条成功 / 失败样本的概率；
- **更细的 $r$**：过程奖励或分级 verifier，使「全错」内部仍可排序，但必须验证过程分与最终成功相关，否则在教刷格式。

这些都会失败：过滤后有效 batch 过小，实际更新频率崩掉，需要动态补采样而不是干等；盲目升温会毁格式，parser 全零，又变回全错组；过程分可 hack 时，全错组表面上有 $\hat{A}$，学的是 Judge。验收仍是 holdout 可验证成功率，不是训练期有效组比例本身。

## 追问

- **加 $\epsilon$ 能不能救出全同组？** 不能。分子是 0，分母不是问题。
- **全错时把相对更短、格式更好的当正例？** 只能当辅助 shaping，且必须证明它与最终成功相关；否则在奖励「写得像对的」。
- **PPO 遇到全对全错会怎样？** Critic 仍可能给出非零 $A$，但若真实回报就是常数，GAE 估的也是噪声。GRPO 只是把「没信号」变得更诚实、更可见。
- **和「难度课程」的关系？** 课程的目标之一就是维持组内方差：太易过滤、太难降档，而不是把所有题永远留在训练集里。
