- 公司：拼多多
- 团队 / 岗位：大模型算法日常实习
- 届别 / 流程：日常实习；二面
- 面试时间：原帖未披露；帖子发布于 2026-03-15
- 来源类型与可信度：牛客候选人原帖，B
- 原始措辞：**“训练不稳定怎么排查”**

先定义「不稳定」，再动手。CE / RL loss 是否 NaN、grad norm 是否尖刺、下游分是否来回跳、还是只是曲线不平滑，后四者处理不同。吞吐抖动（通信卡住、机器抢占）也不要和数值发散混成一句「训崩了」。面试最忌一上来「把 lr 再降一档」：mask 错、NaN、空组不会因为更小步长变正确，只会训得更慢。结论必须指向「改哪一层」，并能用固定小集复现。能复现的才是训练问题；复现不了、只有多卡偶发，先查并行和有效 batch。美团震荡卡的监控项（KL、entropy、有效组）可以复用，但本卡要先给分层清单，避免一上来就谈算法。

## 五层清单：数据到奖励

1. **数据**：空文本、超长截断、错误 mask（prompt 被打 loss 或回答没打上）、偏好对颠倒、突然混入新模板或新语言。先看 batch 里的 token 长度直方图、空样本率和模板版本。数据一换模板，loss 会先跳再「看起来在学」，其实在拟合新格式。
2. **数值**：bf16 溢出、loss scale、embedding 未绑、LoRA $\alpha/r$ 过大、grad clip 没开。NaN 往往在这一层，降 lr 没用。
3. **并行**：ZeRO 漏同步、drop-last 导致有效 batch 跳变、不同 rank 数据不对齐。表现为 loss 周期性尖刺或 rank 间 grad 对不上。
4. **优化**：lr 预热不足、batch 过小、warmup 步数和峰值 lr 不匹配、clip 范围极端。
5. **RL**：reward 尺度跳变、组内全零优势、KL 突然关掉、verifier 超时当 0 分。SFT 先查 1 到 4；GRPO/PPO 必须加上第 5 层。

不要五层一起改。清单是诊断顺序，不是一次上齐的补丁包。

## 复现纪律：小集、单卡、一次一因素

用固定小集 + 单卡（或单数据并行）复现尖刺，再恢复分布式。一次只改一个因素：先修 mask 再动 lr，先开 clip 再改并行。能在小集复现，才说明不是「偶发通信」；小集很稳、一上多卡就炸，才转向并行和有效 batch。记下 seed、数据切片、精度和并行配置，避免「再训一次看看」。

曲线不平滑但 holdout 稳，可能只是 log 间隔或小 batch 噪声，不必当事故。下游分来回跳，要看评测解析器、解码温度和模板是否一起变了，那是评测不稳，不是训练不稳。把「不稳定」写成可观察指标：哪条曲线、哪个 step、是否可复现，再进入五层。

## RL 特有：空组与尺度

GRPO 组内全对全错则优势为 0，有效更新稀疏，曲线会抖。reward 未标准化时，某一批难度突变会让优势爆炸。KL 系数若被关掉或 controller 过冲，策略会突然变成长篇空话，reward 看起来很好、语言已经崩。排查顺序：有效组比例 → reward 直方图 → KL / entropy → 再谈算法。不要先换 PPO。verifier 超时当 0 分会制造假负样本，表现为「突然不会做」；先修超时和默认分，再怀疑策略。

和美团 reward 震荡卡一起答时：本卡给分层清单与复现纪律，那张卡给 KL / 有效组监控项，结论都要落到「改哪一层」。只说「RL 就是不稳」等于没答。

## 追问

- **只降 lr 为什么不够？** mask 错、NaN、空组不会因为更小步长变正确，只会训得更慢。先定位层，再谈步长。
- **如何判断是并行问题？** 单卡小集稳、多卡同数据尖刺，查同步、drop-last 和有效 batch。rank 间 loss 对不上是强信号。
- **loss 平滑但线上抖？** 查解码、模板开关、评测集是否混入训练模板。那是推理 / 评测问题，不要回头乱改优化器。
- **和美团震荡卡怎么一起答？** 本卡给分层清单，那张卡给 KL / 有效组监控项，结论都要落到「改哪一层」，并给出复现实验而不是「再训一次」。
