## 题目描述

给定正整数序列 b 和正整数阈值 d，请构造一个正整数序列 a，使它经过下面的过滤后恰好得到 b。

过滤规则是：第一个元素一定保留；对 a 中此后的每个元素，只有当它不小于“原数组中紧邻它的前一个元素加 d”时才保留。比较对象是原数组的相邻元素，不是上一个被保留的元素。

在所有满足过滤结果的 a 中，先要求 a 的长度最短；若仍有多个答案，再选字典序最小的一条。输入保证存在合法答案。

### 接口与输入输出

实现 `recover(b, d)`，返回构造出的整数列表。b 非空且元素为正整数，d 为正整数。标准输入第一行 `n d`，第二行是 b 的 n 个值，输出 a。

### 示例

```text
recover([5,6,8], 2) -> [5,1,6,8]
recover([2,4,6], 2) -> [2,4,6]
recover([5], 2)     -> [5]
```

第一个结果过滤后保留 5、6、8。公开转载对比较对象存在不同说法；本卡采用与该样例一致的上述原数组相邻定义。

## 解题思路与参考答案

构造很简单：相邻两个保留值如果已经满足 $b_j\ge b_{j-1}+d$，就直接相邻；不满足就在中间插一个 $1$。插入的 $1$ 一定会被过滤掉，又是最小的正整数，所以结果既最短、字典序也最小。这依赖一个假设：过滤时比较的是原数组里的前一个元素。

## 真题记录

淘天研发 2026.04.11 第 2 题（园子的逆转）。正向过程是必留 $a_1$，若 $a_{i-1}+d\le a_i$ 则留下；现在给出 $d$ 和留下的 $b$，构造最短且字典序最小的 $a$。样例是 $b=[5,6,8],d=2$ → `5 1 6 8`。

文档 Part III 标明，多个公开转载对「过滤时比较当前原数组相邻元素，还是上一个保留元素」存在冲突。下面按样例采用「与原数组相邻元素比较」，并写明这个假设。

## 题面

（公开复盘等价转述 + 假设）

正向过滤：给定正整数序列 $a$ 和阈值 $d$。从左到右扫描，$a_1$ 必留；对 $i\ge 2$，当且仅当 $a_i\ge a_{i-1}+d$ 时把 $a_i$ 留下。留下的数按原顺序记为 $b$。

现在给定 $d$ 和 $b$，构造一条正整数序列 $a$，使它过滤后恰好得到 $b$。在所有合法 $a$ 中先要最短，其次字典序最小。题目保证有解。

输入假设第一行是 $n,d$，第二行是 $b_1\ldots b_n$，输出一行 $a$。

为什么按这个定义：如果改成「与上一个保留元素比较」，相邻 $b$ 必须满足 $b_i\ge b_{i-1}+d$，插入任何会被丢掉的数都改变不了这条关系，最短解就是 $b$ 本身，和样例 `5 1 6 8` 矛盾。所以本题按「与原数组相邻元素比较」。

## 思路

看相邻两个保留值 $b_{j-1},b_j$。如果已经满足 $b_j\ge b_{j-1}+d$，直接让它们相邻，$b_j$ 会被留下。如果不满足，中间至少要插一个数 $x$，它要同时满足两件事：$x$ 自己被丢掉，即 $x\lt b_{j-1}+d$；$b_j$ 紧跟在 $x$ 后面时能被留下，即 $b_j\ge x+d$。

取 $x=1$，它是正整数里字典序最小的。$b$ 都是正整数，$b_{j-1}\ge 1$，所以 $b_{j-1}+d\ge 1+d\gt 1$，$1$ 一定被丢掉。样例里 $5$ 后面接 $1$ 再接 $6$：$6\ge 1+2$，合法。

只插一个就够短了，多插只会让序列更长。公开复盘写了「题目保证有解」，所以不会出现 $b_j\lt 1+d$、插了 $1$ 还接不上的数据；真遇到的话，需要改插 $x=b_j-d$（前提是它仍为正，且小于 $b_{j-1}+d$）。

每对相邻 $b$ 各自决定直连还是插 $1$，整体就最短；需要插时选最小的正整数 $1$，前缀字典序就最小。

## 参考代码

```python
import sys


def recover(b, d):
    if not b:
        return []
    a = [b[0]]
    for i in range(1, len(b)):
        prev, cur = b[i - 1], b[i]
        if cur >= prev + d:
            a.append(cur)
        else:
            a.append(1)
            a.append(cur)
    return a


def main():
    data = list(map(int, sys.stdin.read().split()))
    n, d = data[0], data[1]
    b = data[2 : 2 + n]
    ans = recover(b, d)
    print(*ans)


if __name__ == "__main__":
    main()
```

分别检查需要插入、不需要插入和只有一个数。样例插入 1 后，还要按原数组相邻元素的规则正向过滤，确认能还原 b。

```python
assert recover([5, 6, 8], 2) == [5, 1, 6, 8]

```

## 复杂度

时间 $O(n)$，空间 $O(n)$。

## Edge Cases

$n=1$ 输出 $b_1$；整段 $b$ 已经严格按 $d$ 递增时 $a=b$；$d\le 0$ 时「直连」几乎总能成立（公开题按正 $d$ 理解）。

## 追问

**按「与上一个保留值比较」来做，直接输出 $b$ 行吗？**
样例过不去，样例要求输出 `5 1 6 8`。

**插 $0$ 或负数能让字典序更小吗？**
通常不允许，题目要的是正整数序列。

**要不要枚举插入长度，或者二分答案？**
不用，每个间隙插 $0$ 个或 $1$ 个就够了。

**两种定义冲突时怎么办？**
先用样例一句话把比较对象定下来，再写构造，别在两种规则之间折中。
