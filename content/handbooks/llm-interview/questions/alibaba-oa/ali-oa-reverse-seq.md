## 真题记录

- 公司 / 场次：淘天研发 2026.04.11 T2（园子的逆转）
- 正向：必留 $a_1$；若 $a_{i-1}+d\le a_i$ 则留下。现在给 $d$ 和留下的 $b$，构造最短且字典序最小的 $a$。
- 样例：$b=[5,6,8],d=2$ → `5 1 6 8`。
- 文档 Part III 标明：多个公开转载对「过滤时比较当前原数组相邻元素，还是上一个保留元素」存在冲突。下面按样例采用「与原数组相邻元素比较」，并写明该假设。

## 题面

（公开复盘等价转述 + 假设）

正向过滤：给定正整数序列 $a$ 和阈值 $d$。从左到右扫描，$a_1$ 必留；对 $i\ge 2$，当且仅当 $a_i\ge a_{i-1}+d$ 时把 $a_i$ 留下。留下的数按原顺序记为 $b$。

现在给定 $d$ 和 $b$，构造一条正整数序列 $a$，使它过滤后恰好得到 $b$。在所有合法 $a$ 中先要最短，其次字典序最小。题目保证有解。

输入假设：第一行给出 $n,d$，第二行 $b_1\ldots b_n$。输出一行 $a$。

假设说明：若改成「与上一个保留元素比较」，则相邻 $b$ 必须满足 $b_i\ge b_{i-1}+d$，插入任何会被丢掉的数都改变不了这条关系，最短解就是 $b$ 本身，与样例 `5 1 6 8` 矛盾。因此本题按「与原数组相邻元素比较」。

## 思路

相邻两个保留值 $b_{j-1},b_j$ 若已经满足 $b_j\ge b_{j-1}+d$，把它们直接相邻即可，$b_j$ 会被留下。若不满足，中间必须插入至少一个数 $x$，使得：

- $x$ 自己被丢掉：$x\lt b_{j-1}+d$
- $b_j$ 紧跟 $x$ 时被留下：$b_j\ge x+d$

取 $x=1$（正整数里字典序最小）。因为 $b$ 是正整数，$b_{j-1}\ge 1$，故 $b_{j-1}+d\ge 1+d\gt 1$，$1$ 一定被丢掉。样例里 $5$ 后面接 $1$ 再接 $6$：$6\ge 1+2$，合法。

只插一个就够短：多插只会使序列更长。公开复盘写「题目保证有解」，因此不会出现 $b_j\lt 1+d$ 这种插 $1$ 之后仍接不上的数据；若现场遇到，需要改插 $x=b_j-d$（若仍为正且小于 $b_{j-1}+d$）。

每对相邻 $b$ 独立决定「直连或插 $1$」，整体最短；需要插入时选最小正整数 $1$，前缀字典序最小。

## 参考代码

```python
import sys


def recover(b, d):
    if not b:
        return []
    a = [b[0]]
    for i in range(1, len(b)):
        prev, cur = b[i - 1], b[i]
        if cur >= prev + d:
            a.append(cur)
        else:
            a.append(1)
            a.append(cur)
    return a


def main():
    data = list(map(int, sys.stdin.read().split()))
    n, d = data[0], data[1]
    b = data[2:2 + n]
    ans = recover(b, d)
    print(*ans)


if __name__ == "__main__":
    main()
```

边界：$n=1$ 输出 $b_1$；整段 $b$ 已严格按 $d$ 递增则 $a=b$；$d\le 0$ 时「直连」几乎总能成立（公开题按正 $d$ 理解）。

## 复杂度

时间 $O(n)$，空间 $O(n)$。

## 易错 / 面试追问

- 按「与上一个保留值比较」直接输出 $b$，样例过不去。
- 插入 $0$ 或负数来凑字典序，通常不允许。
- 枚举插入长度或二分答案，本题插入 $0$ 或 $1$ 个即可。
- 追问冲突口径：先用样例一句话明确固定下来比较对象，再写构造；不要在两种规则之间折中。
