## 题目描述

给定非空整数数组 a，可以执行任意次操作：选择两个不同位置 i、j，把 `a[i]` 改为 `a[i] + a[j]`，并把 `a[j]` 改为 0。允许一次操作也不做，也允许后续操作继续使用先前生成的值。

操作结束后，每个前缀取一个最大元素，再把这些最大值相加：长度为 n 的数组共有 n 个前缀。求在所有可达最终数组中，这个“前缀最大值之和”的最大可能值。

### 接口与输入输出

实现 `max_prefix_max_sum(a) -> int`，只返回最优分数，不要求返回操作序列或最终数组。标准输入版本先给 n，再给 n 个整数，输出一个整数。公开材料没有可靠给出精确数据上界，不另加未公开限制。

### 示例

```text
max_prefix_max_sum([3,2,-1]) -> 15
max_prefix_max_sum([-1])     -> -1
max_prefix_max_sum([-2,-3])  -> 0
```

例如分数 15 表示三个前缀的最大值之和能够达到 15，并非数组所有元素直接求和。

## 解题思路与参考答案

这题不用模拟：有正数时答案是 $nP$，$P$ 是所有正数之和；没有正数时，$n=1$ 输出原值，$n\ge 2$ 输出 $0$。融合操作反复做下来等于把能量任意重新分配，而前缀最大值之和最喜欢一个放在最左边的大数。

## 题面

（公开复盘等价转述）给定长度为 $n$ 的整数数组 $a$。一次操作选择两个不同下标 $i,j$，执行 $a_i\leftarrow a_i+a_j$，再令 $a_j\leftarrow 0$。操作次数不限。完成后计算

$$
\sum_{k=1}^{n}\max(a_1,a_2,\ldots,a_k)
$$

求这个值的最大可能值。

公开复盘给出的样例是 $[3,2,-1]\to 15$、$[-1]\to -1$。$n$、$a_i$ 的精确上下界在可引用文本里没有完整公开，实现按 $O(n)$ 写即可。

输入第一行是 $n$，第二行是 $n$ 个整数；输出一个整数。

## 思路

操作是把一颗宝石的能量全部转到另一颗，原位置留下 $0$。反复做下去，就等于把能量重新分到若干位置，其余位置为 $0$。总和守恒，但负数可以被转到某处，再被别的正能量「吃掉」，也可以被挪走，在前缀里留下 $0$。

前缀最大值序列单调不降，要让它们的和最大，就要让尽量多的前缀最大值变成尽量大的正数。能堆出来的最大正能量是所有正数之和 $P=\sum_{a_i\gt 0}a_i$，负数不用加进这个堆，加进去只会变小。

把 $P$ 放在下标 $1$，之后每个位置的前缀最大值都至少是 $P$，总和是 $nP$。放到更靠后的位置，前面几个前缀最大值会变成 $0$ 或负数，一定不会更好。拿样例 $[3,2,-1]$ 看，$P=5$，堆到第一个位置后三个前缀最大值都是 $5$，答案 $15$。

没有正数时分两种情况。$n=1$ 时无法操作，答案就是 $a_1$，可能是负数或 $0$。$n\ge 2$ 时可以把某个负数挪到另一个位置，让下标 $1$ 变成 $0$，于是每个前缀最大值都是 $0$，答案为 $0$。

正能量全堆在最左边，前缀最大值就被钉在 $P$，负数清零也不会把已经得到的 $P$ 拉低，所以不用真的模拟多次融合。

## 参考代码

```python
import sys


def max_prefix_max_sum(a):
    n = len(a)
    if n == 0:
        return 0
    pos = sum(x for x in a if x > 0)
    if pos > 0:
        return n * pos
    if n == 1:
        return a[0]
    return 0


def main():
    data = list(map(int, sys.stdin.read().split()))
    if not data:
        return
    n = data[0]
    a = data[1 : 1 + n]
    print(max_prefix_max_sum(a))


if __name__ == "__main__":
    main()
```

## 复杂度

时间 $O(n)$，额外空间 $O(1)$。

## Edge Cases

全 $0$ 时 $P=0$，$n$ 任意，答案都是 $0$；只有一个负数时消不掉；`[0,-1]` 本身已经是 $0$。其他语言里乘积 `n * pos` 要用 64 位。

## 追问

**直接写循环模拟融合行不行？**
既慢，又容易在负数上选错吸收位置。上面的推导说明结果只取决于 $P$ 和 $n$。

**能不能把负数也加进 $P$，或者把 $P$ 堆到数组最大值所在的下标？**
都不对。负数加进去只会让 $P$ 变小；堆到最大值的下标、不放在最左边，前面的前缀最大值就吃不到 $P$。

**$n=1$ 且是负数，能输出 $0$ 吗？**
不能。$n=1$ 时一次操作都做不了，只能输出原值。

**如果操作改成只能向相邻位置合并呢？**
那就没法任意重分配了，要改成区间 DP。公开题面不是这个版本。
