## 真题记录

- 公司：小红书
- 团队 / 岗位：NLP / 多模态 / 大模型实习生
- 届别 / 流程：实习；一面
- 面试时间：2026-04-08 19:00
- 来源类型与可信度：牛客候选人原帖，A
- 原始措辞：**“MMKG-RAG，如何分块，实体和关系的抽取与合并”**

这块容易直接答成按纯文本 token 长度切笔记，或让模型空想「代言」「同款」边。小红书笔记是图文混排：图注离开图片、表格被横切，检索会召回半截事实。实体要跨模态对齐，关系必须能指回证据。选块和冲突处理见 `pdd-pick-relevant-chunks`；RAG 短板见 `xiaohongshu-rag-limits`。

## 分块：按版面和语义单元

笔记按段落 + 图片区域切；表格按行组；视频按镜头关键帧配字幕。每块带模态类型、坐标 / 时间和权限。图注、OCR、价格条和对应图片留在同一块或用显式边连上，不要把图注单独扔进文本索引。重叠只为跨图文指代留缝，不要整页复制。切太碎会丢关系，切太大则召回噪声；粒度应能回答「这块能否独立支撑一个槽位」。权限随块走，隐私图不能因文本召回被带出。

## 抽取：实体带证据，关系禁空想

文本侧 NER / 开放关系，视觉侧物体、OCR、版面。每条实体带证据 span 或框；关系必须能指回证据块，禁止模型补「代言」「同店」这类高风险边。开放抽取要收口到业务 schema（商品、地点、价格、功效），否则图会膨胀到不可用。低置信抽取进待审，不直接进可检索图。功效 / 医疗主张默认不建边，和幻觉策略一致，见 `xiaohongshu-hallucination-prompt`。

## 合并：候选对齐，冲突留多值

同名、别名词典、视觉相似和属性重叠做候选，阈值下人工或二次模型确认。冲突（两个价格、两个产地）保留多值并打来源，不要静默覆盖。图更新要版本化，检索时实体召回与文本块召回融合，再按槽位覆盖和多样性截断，见 `pdd-pick-relevant-chunks`。评测看实体对齐错误、无证据边比例、冲突是否被抹平，以及图文拆开后的召回失败。小红书笔记同款、拼图、水印文案很多，视觉相似不等于同一商品；合并阈值宁严勿松，松了图会把两个价格并成一个「真值」，生成阶段再难纠。分块、抽取、合并是一条链路：切错了，后面抽取再准也是半截证据。

## 追问

- **为什么不能按固定 token 切？** 会切断图注、表格行和价格，造成半截事实被当成完整证据。
- **没有证据的关系怎么办？** 不入库。宁可不连，也不要让生成阶段引用空想边。
- **同名商品怎么合并？** 先候选再确认；属性冲突留多值，不要用最高分覆盖。
- **图更新了旧边怎么办？** 版本化。检索绑定图版本，避免和生成模板各用各的快照，见 `xiaohongshu-rag-limits`。
