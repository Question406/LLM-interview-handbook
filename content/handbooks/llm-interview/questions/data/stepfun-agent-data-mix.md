- 公司：阶跃星辰（StepFun）
- 团队 / 岗位：Agent 算法
- 届别 / 流程：原帖未披露
- 面试时间：原帖未披露；帖子发布于 2026-03-30
- 来源类型与可信度：牛客候选人原帖，B
- 原始措辞：**“怎么优化RL训练agent调用工具的数据，数据配比策略是怎样的”**

陷阱是把配比讲成「成功 : 失败 = $1:1$」或「每种工具条数一样」。评委要的是：**采样服务于奖励与探索**，不是凑齐 jsonl。池子被「一搜就中」占满时，group 内几乎全对，advantage 塌成零，政策学不会澄清、换工具和失败恢复。同面的奖励设计见 `stepfun-agent-tool-training`；配比是奖励的采样侧，不要两套故事。

## 先分桶，再设上限

SFT 冷启动要覆盖合法 schema、典型失败恢复和拒绝越权，这是格式地基，不是 RL 主信号。RL 池按 **工具、步数、失败类型、环境版本** 分桶：低成功桶提高采样，热轨迹设上限，防止一条「总能搜到」的路径刷奖励。有效指标是各桶 holdout 成功率与有效 group 比例，而不是总条数。选例逻辑与 `data-rlvr-select`、`meituan-easy-hard-sft-balance` 同类：难度落在当前 policy 可探索区间。

优化动作：用 verifier 丢掉不可回放、schema 非法或环境版本不匹配的轨迹（`data-verifier`）；成功但步数虚高的轨迹降权，避免长度投机（`data-length-hacking`）。过期 API / 沙箱的旧轨迹必须丢或重放标注，否则奖励在教过时行为。

## 配比实验怎么做才可复现

一次只改一类比例（例如长尾工具或「需澄清」桶），同时看：该类 holdout 是否升、锚点任务是否掉、平均步数与工具错误率。来源级配额比按原始 volume 拼接更稳，思路同 `kuaishou-sft-source-mix`。Agent 后训练阶段划分见 `byte-agent-posttrain-data-stage`：SFT 示范正确轨迹，RL 要可打分难例，不要把两套数据混成同一份。

失败模式：只堆成功演示 → 探索消失；不过滤过期环境 → 线下涨、线上崩；配比扫时不看锚点 → 长尾工具学会了、主路径回归。

## 一个可落地的配比账本

把每个 prompt 看成「当前政策下的难度标签」，而不是静态题型。每周用当前 actor 在 holdout 上估 pass@$1$ 与 pass@$k$：差接近零说明该桶该降权或移出 RL，改回 SFT 示范；差大而 pass@$1$ 低说明值得加采样。工具维度再切一刀：主路径工具（搜索、读文件）设上限，避免占满 batch；长尾工具（冷门 API、少见错误码）设下限，但每条必须可回放。失败恢复轨迹单独记账——「第一次 call 错、第二次改参成功」比「一次成功」更值钱，因为 credit 在过程上。

配比数字要能复述：例如主成功不超过 $30\%$，失败恢复 $25\%$，长尾工具 $20\%$，需澄清 / 拒答 $15\%$，其余为锚点通用。这些比例不是真理，是实验起点；改变时只动一维，并写清环境 hash。和环境版本绑定的轨迹一旦 schema 变字段，整桶作废，不要靠 prompt 里写「忽略旧字段」混过去。线上工具超时、空结果这类 case 应进失败桶而不是丢掉，否则政策从未见过真实噪声。

监控上同时看：有效 group 率、平均工具步数、非法 call 率、各桶 reward 方差。方差掉下去时先查配比是不是被简单成功淹没，再查奖励是不是被长度或格式投机主导。和 GRPO 全同组问题是同一件事：配比决定你能不能采到可比较的 $G$ 条。配比账本要进实验记录，和 `dataset_version`、环境 hash、reward 版本绑在一起，否则下周无法回答「这一版成功率为何掉」。线上工具超时、空结果、权限拒绝必须进失败桶，政策才能在真实噪声里学会换工具而不是只会演示路径。采样温度再高，池子里没有难例也探索不出来。

## 追问

- **条数 1:1 为什么不够？** 简单成功轨迹梯度便宜、条数又多，会淹没难例；应按桶成功率与有效 group 率调采样。条数相等掩盖了「一条热轨迹被复制一万次」。
- **过期环境怎么处理？** 丢弃或在新环境重放标注，不能靠 importance weight 硬修不可回放轨迹。环境 hash 进样本元数据，对不上就拒收。
- **和奖励设计怎么分工？** 奖励定义「什么算对」；配比决定「哪些对/错被看到」。先冻结 reward，再扫 mixture，否则分不清是奖励漂了还是采样漂了。
- **失败恢复要不要当成功？** 最终成功可以给正奖励，但步数虚高要降权；过程中的非法 call 仍应罚，避免学会「先乱调再碰对」。
- **SFT 和 RL 能共用一份配比吗？** 不能。SFT 要覆盖合法格式与拒答口径；RL 要难度带和方差。混用会把简单示范重复送进 group，有效 group 率掉。
