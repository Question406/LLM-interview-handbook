## 真题记录

- 公司：腾讯 · 混元
- 岗位：大模型日常实习；一面
- 来源类型与可信度：牛客候选人原帖，A
- 原始措辞：**“LoRA 和全参微调你会怎么做对比实验？”**

常见误区是：只说「LoRA 省显存所以更好」。评委要的是同一数据、同一评测、只改更新范围的对照表，外加遗忘与成本。LoRA 省的是优化器状态和可回滚适配器，不是免费的同等表达力。机制侧（$A$ 随机、$B$ 全零）见同厂 `tencent-lora-ab-init`、`kuaishou-lora-ab-init`；本题问实验设计。插层位置见 `meituan-lora-not-after-ln`，量化适配见 `arch-qlora`。

## 最低对照怎么摆

冻结除 LoRA 外全部权重 vs 全参更新。对齐：同一训练集与 packing、同一评测集与解码；学习率、有效 batch、epoch 对齐或按可训参数缩放，避免将 LoRA 的调参不足误判为方法无效。记录：可训参数量、峰值显存、吞吐、步数到收敛。指标必须分组统计：目标任务、通用指令、知识保持 / 基座原能力。只报目标任务涨、不报 MMLU / 指令回归，实验无效。

再扫 rank $r$、$\alpha$ 和插入层（attn 投影 vs MLP）。$r$ 过小欠拟合，$r$ 过大接近全参却仍多一套超参。实现细节可对照 `code-lora`。QLoRA 是另一轴（量化基座 + LoRA），不要和「全精度 LoRA vs 全参」混成一张表。

## 怎么下结论

数据少、要为多租户挂多个适配器、或必须快速回滚时优先 LoRA。要改推理风格、领域分布变化较大、或目标是把基座「变成另一个产品人格」时再考虑全参。结论应附对照表：例如「目标 +$x$，通用 $-y$，显存 $-z\%$」。若 LoRA 目标不够、全参通用掉太多，选项是加大 $r$、多插层、或在全参训练中加强旧数据回放，而不是只表达方法偏好。

失败模式：学习率不缩放导致 LoRA 学不动；评测只看训练集同类题；把初始化没扫的 LoRA 当成方法失败。

## 对照表里必须出现的列

一张最低限度的表：方法（全参 / LoRA-$r$ / QLoRA）、可训参数、峰值显存、token/s、目标任务、通用指令、知识保持、训练步数。缺任何一列，结论都可以被质疑「你只是没训够 / 没调参 / 没看遗忘」。LoRA 的 $\Delta W=BA$，$B$ 全零起步保证初始输出与基座相同（`tencent-lora-ab-init`），所以「第一个 step 的 loss 应接近基座」也是健全性检查：如果训练刚开始就出现数值异常，是 lr 或插入位置错了，不是 LoRA 本身不行。插入位置不要放在 LayerNorm 之后当残差的错误位置（`meituan-lora-not-after-ln`）。

数据条件要固定：同一份监督微调（SFT）数据、同一 packing、同一 chat template。否则你比较的是数据，不是更新范围。若全参用了更高 epoch，LoRA 却早停，表上要注明，不能把欠拟合当成方法差异。多适配器场景是 LoRA 的真实优势：同一基座挂多个 $r$ 很小的头，服务时按路由加载，全参做不到廉价隔离。领域大移（从通用对话改成深度代码风格）时，低秩可能不够，这时应先加 $r$、多插 MLP，再考虑全参，而不是第一步就全参。

成本账：全参优化器状态约为参数的 $2\sim 3$ 倍（Adam），LoRA 只为低秩矩阵存状态，这才是省显存的主因。推理若合并权重，延迟接近全参；若按适配器动态加载，则多一次 $BA$ 的计算。面试把「训练省」和「推理省」分开说。对照实验的结论必须能写成「在何种数据规模、何种遗忘预算下选谁」，而不是方法站队。若 LoRA 在扫完 $r$ 与插层后目标仍差一截、且通用回归可接受，再上全参；若全参通用掉太多，应加 replay 或回到更高 $r$ 的 LoRA，而不是认定全参失败。同一张表上 QLoRA 单列，避免把量化误差算进低秩头上。

## 追问

- **学习率怎么对齐？** 可训参数差几个数量级，常把 LoRA lr 设高一档或按 $\alpha/r$ 缩放，并做小网格，而不是共用一个数。
- **如何测遗忘？** 冻结基座评测集（通用指令、原领域），报告回归幅度，不只看目标任务。全参更新更容易影响基座原有能力，必须报。
- **和 A/B 初始化题怎么分工？** 初始化问 $\Delta W=0$ 的起步；本题问更新范围对照。两题可以同一面先后出现。
- **QLoRA 算 LoRA 还是全参？** 算量化基座上的 LoRA，应单列，不要和全精度 LoRA 挤在同一格。
- **什么时候可以不下全参？** 数据少、要多租户适配器、或目标只是浅层风格时；先把 $r$ 和插层扫完再下结论。
