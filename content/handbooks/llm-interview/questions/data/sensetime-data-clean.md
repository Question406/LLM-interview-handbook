## 真题记录

- 公司：商汤
- 团队 / 岗位：多模态大模型算法实习
- 届别 / 流程：一面
- 来源类型与可信度：牛客候选人原帖，A
- 原始措辞：**“数据是哪来的，怎么洗的，怎么保证准确性”**

一面三问要按账本答：来源许可与场景覆盖 → 版式 / 语言 / 模糊过滤 → 字段级抽检。不能只答「用模型洗」。适用条件是 OCR / 单据理解这种「字段对错能核验」的流水线；开放域聊天的清洗目标不同（毒性、PII、近重复），不要硬套。失败模式是同一个大模型又生成又清洗，把模型偏好洗进训练集。商汤多模态岗听的是你能不能把扫描件、公开 PDF、合成扰动分开记账，并指出哪一层的通过率在撑总准确率。

## 来源与清洗可复现

来源：有授权的业务扫描件、公开文档、合成扰动，各记授权范围和拍摄条件。合成单独标记，避免评测泄漏（`data-contamination`）。清洗：去模糊、去重复版式、统一方向、剔除不可读；同一张发票扫二十次只留一张。近重可用 hash + 版式 embedding，但字段值不同的联次单据不要当重复删掉，那是 `data-semantic-dedup` 在多模态上的误杀。

合成旋转 / 模糊扰动补覆盖，但必须与真实扫描分层记账，评测不能只吃合成。语言与版式（横竖、表格密度、印章遮挡）要进分桶，否则「洗过了」只对训练集好看。

## 准确性：双标 + 分层通过率

关键字段（金额、税号）双标加仲裁；自动规则抓空值和非法日期；抽检按字体 / 光照 / 表格密度分层，每层报通过率。保证不是「人工看过」，而是可复现的一致性和分层通过率。版式 OOD 集（未见发票模板、强反光、手写混印）单独报，防只在训练版式上准。多轮单据对话（`sensetime-multiturn`）依赖这些槽位是干净的；字段错了，后面状态机会把错槽当已确认。

对照：只模型预标、规则+抽检、双标。看分层通过率、双标一致、OOD 字段错。模型预标可以提速，但不能当准确性证明。

一面「数据从哪来」要主动讲许可：业务扫描件有没有授权范围、公开 PDF 是否允许训练、合成扰动是否可能复现真实税号。说不清许可，后面清洗讲得再细也减分。准确性证明给数字也要分层：印刷体 / 表格 / 印章遮挡 / 手写各报双标一致，不报一个总准确率。发现某层崩了，先停该层入训、补采集或改拍摄条件，而不是加大模型清洗力度。来源要可审计，清洗要可复现，准确性靠双标和 OOD，不靠「模型洗过」。后面纠错和过拟合实验都建立在这套账本上。

## 追问

- **准确性怎么证明？** 双标一致性 + 分层通过率 + 版式 OOD，不说「人工看过」。
- **为什么不能只用大模型洗？** 会把教师偏好和幻觉洗进金标；规则和双标才是可审计门禁。
- **合成扰动算真实覆盖吗？** 算补覆盖，单独标记；评测以真实扫描为主，防泄漏和分布塌缩。
- **和聊天语料清洗差在哪？** 单据看字段可核验；聊天看毒性/PII/近重。规则集不能一把梭。
