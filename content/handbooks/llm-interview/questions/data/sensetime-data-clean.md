## 真题记录

- 公司：商汤
- 团队 / 岗位：多模态大模型算法实习
- 届别 / 流程：一面
- 来源类型与可信度：牛客候选人原帖，A
- 原始措辞：**“数据是哪来的，怎么洗的，怎么保证准确性”**

三个问题我会按一本可追溯的账来答：数据从哪来、各占多少、授权到哪；清洗每一步怎么做、能不能复现；准确性用双标一致率、分层通过率和 OOD 集来证明。只答一句「用模型洗」不够，同一个大模型又生成又清洗，会把模型自己的偏好洗进训练集。这套做法适用于 OCR、单据理解这种字段对错能核验的流水线；开放域聊天的清洗目标不一样，看的是毒性、PII 和近重复，别硬套。

先讲来源，许可要主动说。来源一般有三类：有授权的业务扫描件、公开文档、合成扰动，每类都记授权范围和拍摄条件。业务扫描件授权到哪、公开 PDF 是否允许训练、合成扰动会不会复现真实税号，这几件事说不清，后面清洗讲得再细也减分。商汤多模态岗想听的，是你能分别记录扫描件、公开 PDF 和合成扰动的来源与占比，并指出哪一层的通过率在撑总准确率。合成的旋转、模糊扰动可以补覆盖，但要和真实扫描分层记账、单独标记，避免评测泄漏（`data-contamination`），评测要以真实扫描为主。

清洗是去模糊、去重复版式、统一方向、剔除不可读。比如同一张发票扫了二十次，只留一张。近重复可以用 hash 加版式 embedding 找，但联次单据长得一样、字段值不同，不能当重复删掉，这是 `data-semantic-dedup` 在多模态上容易出的误杀。语言和版式（横竖、表格密度、印章遮挡）要进分组统计，否则「洗过了」只是训练集上好看。

准确性这块，金额、税号这类关键字段双人标注加仲裁；自动规则抓空值和非法日期；抽检按字体、光照、表格密度分层，每层报通过率，印刷体、表格、印章遮挡、手写各报双标一致，不报一个总准确率。再单独做一个未见版式的 out-of-distribution 数据（OOD）评测集，比如没见过的发票模板、强反光、手写混印，防止模型只在训练版式上准。某个分组的准确性明显掉了，先停这一层入训，补采集或改拍摄条件，别去加大模型清洗的力度。

对照可以摆三档：只用模型预标、规则加抽检、双标，比较分层通过率、双标一致率和 OOD 字段错误。模型预标能提速，但当不了准确性的证明。这本账也是后面的基础：多轮单据对话（`sensetime-multiturn`）依赖这些槽位是干净的，字段错了，后面的状态机会把错槽当成已确认，纠错和 overfitting 实验也都建立在这套账本上。

## 追问

**准确性具体怎么证明？**
双标一致率、分层通过率、版式 OOD 三样一起给。说「人工看过」不算证明。

**只用大模型洗为什么不行？**
会把教师的偏好和 hallucination 洗进金标。规则和双标才是可审计的 acceptance checks。

**合成扰动算真实覆盖吗？**
算补覆盖，要单独标记。评测以真实扫描为主，防止泄漏和分布塌缩。

**和聊天语料的清洗差在哪？**
单据看的是字段能不能核验，聊天看毒性、PII 和近重复，两套规则不能直接套用。
