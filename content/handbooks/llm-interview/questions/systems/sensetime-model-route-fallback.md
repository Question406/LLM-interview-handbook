## 真题记录

- 公司：商汤
- 岗位：大模型算法应用实习；二面
- 来源类型与可信度：牛客候选人原帖，A
- 原始措辞：**“多模型如何动态路由，比如不同模型适合不同视频场景时，怎么根据视频特征、任务特征、成本、延迟和效果选模型”**；**“所有模型超时或故障时怎么兜底，什么时候规则引擎，什么时候人工，服务恢复后怎么回切”**；**“能不能让系统自动发现问题、尝试策略、验证效果，并自动生效和回滚”**

这块容易按模型名字路由（「夜间用大模型」），或把自动调参做成不可回滚的全量生效。路由特征应是任务类型、分辨率、时延预算、目标尺寸、历史误报/漏报，而不是品牌。视频场景还要区分硬安全（烟感、入侵）和理解类（行为描述）：前者不能只靠生成模型。超时先降级小模型或规则，再人工；恢复后灰度回切并对比误报。自动发现问题必须带金标回放和一键回滚，否则是事故生成器。Serving 上这是 admission + 模型池，和 LLM continuous batching 同一类「先保 SLA 再选质量」。

## 路由：规则打底，效果做探索

先规则：夜间红外走低光模型 A，高清人脸走 B，低分辨率/远距走检测+裁剪再识别，时延预算紧走蒸馏小模型。特征包含场景标签、目标框大小、FPS、是否含人脸/车牌等合规约束。再用在线效果做小流量探索：同一路视频影子打到候选模型，比较漏报、误报、延迟、GPU 成本。路由表要版本化，key 是特征桶而不是「模型 v3」。成本约束写进路由：贵模型只给高价值任务（人脸核验），巡检理解用便宜模型。不要让大 VLM 默认吃所有路，队列一满，所有场景一起超时。

和 LLM 网关类似：小请求小模型，难请求大模型；这里难的是低质量画面和高风险任务，不是 token 长度。

## 兜底与回切

分层：规则引擎管硬安全（烟感、门磁、绊线），模型全挂时物理规则仍在。模型管视觉理解。人工管不确定与法律后果（误报封门、漏报责任）。超时链：主模型 deadline → 小模型 / 轻量检测 → 规则告警或「降级中」工单 → 人工。不要等大模型 30 s；视频是流，晚到的框没有意义。熔断按模型实例，不要一条坏 GPU 拖垮路由。

回切：服务恢复后先影子流量对比误报/漏报，再按百分比放量。指标回不到基线就停。版本和路由表一起回滚。缓存的检测结果要带模型版本，回切后不能把旧框当新结果。

## 自动调参必须能回滚

「自动发现问题、尝试策略、验证、生效」可以做，但生效必须有：金标回放、影子对比、小流量、一键回滚、变更审计。没有这五件就是把探索直接推全量。验证窗口要覆盖昼夜和天气，否则白天调好的阈值晚上炸。最后我会分三句说：路由看特征与 SLA，兜底看责任分层，自动生效看回滚。

视频多模型路由不要做成「if 夜间 then 大模型」。先把任务分成硬安全和理解：烟感门磁绊线必须规则可兜底；行为描述、以图搜图才进模型池。路由特征用场景标签、分辨率、目标尺寸、时延预算、合规约束和历史误报漏报，成本约束决定贵模型只给高风险桶。Serving 上这是模型池 admission：大 VLM 默认吃所有路，队列一满全场景超时。超时链必须短于帧间隔：主模型 → 小模型/检测 → 规则或降级工单 → 人工，不能阻塞等 30 秒。回切用影子流量对比误报漏报再灰度，路由表和模型版本一起滚。自动调参可以探索，生效必须金标回放、小流量、一键回滚和审计；没有回滚的「自动发现问题并生效」就是事故生成器。验证窗口覆盖昼夜天气。面试按特征路由、责任分层、回滚闸门三块答，比报一串模型名字像做过线上。

## 三句话分开说

路由看场景特征和 SLA，不看模型昵称。兜底看责任：规则管硬安全，模型管理解，人工管法律后果。自动生效看回滚闸门：金标、影子、小流量、一键回滚、审计。视频流超时链必须短于帧间隔。回切对比误报漏报再灰度。没有回滚的自动调参不要上线。

## 追问

- **为什么不能只看模型名字？** 同一名字换版本、换量化、换分辨率适配，效果都会变。应按场景标签、目标尺寸、时延预算、历史误报漏报路由。特征桶要版本化，才能回放和回滚。
- **规则和模型谁优先？** 硬安全（烟感、门磁、绊线）规则永远可兜底，模型全挂时闸门还在。模型提高理解和召回，但不能当唯一闸门。法律后果不确定时交给人工。
- **全超时怎么办？** 主模型 deadline → 小模型或轻量检测 → 规则告警或降级工单 → 人工。视频是流，晚到的框没有意义，不要阻塞等大模型几十秒。熔断按实例，坏 GPU 不要拖垮路由。
- **回切为什么要影子流量？** 恢复后的输入分布、阈值、权重可能已变。先对比误报/漏报与基线，再按百分比放量。路由表和模型版本一起滚。指标回不到基线就停。
- **自动生效最危险的是什么？** 没有回滚的全量推送。探索可以自动，上线必须有金标回放、小流量和一键回滚。验证窗口覆盖昼夜和天气，否则白天调好的阈值晚上炸。
