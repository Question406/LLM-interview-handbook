区分这几类，先看学习信号从哪里来。监督学习拿已有标签学输入到答案的关系；无监督学习没有任务标签，通常寻找聚类、低维结构或数据分布；半监督学习同时利用有标签和无标签样本。自监督学习则自己从数据构造目标，比如让模型预测被遮住的内容。[Google Machine Learning Glossary](https://developers.google.com/machine-learning/glossary) 对这些训练方式给出了定义。

这里的「监督」指用于计算误差的目标，并不要求有人盯着训练。订单是否退款、设备之后是否故障，都可以从业务记录生成监督标签。自监督也有训练目标，只是目标直接来自输入数据的另一部分，因此不依赖逐条人工标注。

比如有一批商品图片：人工标好「鞋、包」后训练分类器，是监督学习；只按外观相似度分组，是无监督学习；只标其中一小部分，再结合其余图片训练分类器，是半监督学习；遮掉一块图片，让模型重建它，是自监督任务。自监督预训练后用少量类别标签微调，可以组合进半监督方案。

选方法时，我会先确认最终要预测什么，再看标签质量、未标注数据与目标场景是否接近，以及怎样留出独立评测集。无标签数据多，并不自动意味着其中的结构对目标有用。

## 追问

**聚类出来的几个组就是业务类别吗？**
不一定。相似度可能主要反映背景、颜色或拍摄设备，需要用业务样例检查每组到底代表什么。

**自监督和半监督是不是互斥？**
不是。两者描述的重点不同：自监督说目标怎样构造，半监督说训练是否联合使用有标签和无标签数据，可以出现在同一流程里。

**模型给无标签样本打伪标签，可信吗？**
要验证。高置信预测也可能系统性出错，直接回灌会放大错误；应该在独立有标签集上检查收益，并审核新增伪标签的分布。
