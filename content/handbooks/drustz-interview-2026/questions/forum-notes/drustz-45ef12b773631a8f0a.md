## Constraints

- `1 <= limit <= 10^5`
- `0 <= shards.length <= 10^4`
- `-10^9 <= start <= end <= 10^9`
- Each shard string has the format `"id:start:end"`.
- Shard identifiers are distinct and contain no colons.
