## 14. 面试前一页速记

**定位**：测量系统设计题。交付物是一台仪器，不是一个 agent。**先测噪声，再定题量。**

**元指标七件**：区分度 / test-retest 噪声 / 可复现 / 与线上秩相关 / 抗污染 / 成本 / 可诊断。

**样本量算术**：未配对 $\mathrm{SE}=\sqrt{2p(1-p)/n}$，$p{=}0.5$、$n{=}500$ → SE 3.2pt → 只能分辨 ~9pt；配对（不一致率 0.2）→ ~5pt。**榜单前三名在噪声内是常态。**

**四条结构差异**：多步（误差累积，0. $98^50$ =0.36）/ 有状态（reset 速度决定 $k$）/ 有副作用（沙箱+回滚）/ 路径不唯一（约束满足 ≠ 脚本匹配）。

**过程 vs 结果的实证**：153 条退款轨迹，final_only 下合规与三类违规**全是 1.000 平局**；加效率项后 skip_step **0.800 > compliant 0.750**。→ 过程是**否决维度**不是加权项。三分类判分：success / incomplete / violation。

**过程评分四法**（可靠性降序）：必经点断言 → 中间状态比对 → **反事实探针**（治"蒙对"，成对任务的行为差分）→ judge 读 trace（不做主 gate）。断言绑**数据流**（refund 的 order_id 必须来自 lookup 的返回），否则 agent 会"调了但不看返回值"。

**环境三档**：全确定（回归 CI）/ **受控随机 + 注入故障**（主集，测 recovery）/ 真实随机（20–50 题保真度calibration）。可复现锁四层：依赖 digest / 状态快照 / **时钟** / seed。

**verifier 要被测试**：每题配 gold 轨迹 + known-bad 轨迹，CI 每日跑。先例：OSWorld 原版 ~10% 坏题，SWE-bench Pro grader ~1/3 试次误判。

**环境卫生**：strip `.git`、测试文件延后挂载、网络 deny、verifier 只读、真实副作用硬失败不静默 mock。

**任务来源**：真实 50–70% / 半合成 20–40%（造反事实对）/ 全合成 10–20%（防污染）。**可验证性阶梯 L0 终态 → L1 测试 → L2 短答案 → L3 约束 → L4 rubric → L5 人工**，能往上走就往上走；但留 50–100 题 L5 子集做对齐，覆盖缺口写第一页。

**分层**：smoke 5%（$p{\approx}1$，测 harness）/ core 60%（$p$ 0.3–0.7，$k$=5–8）/ frontier 25%（$p$<0.15）/ adversarial 10%。**RL 里丢 $p{=}0$ 的题，benchmark 里不能丢**——移到 frontier。必须有**不可能任务 / 该拒绝的任务**。

** $\mathrm{pass}^k$ **：$p{=}0.7 \Rightarrow \mathrm{pass}@8{=}99.99\%$，$\mathrm{pass}^8{=}5.7\%$。**报 per-task $p$ 的分布不报均值**：0.7/0.3 双峰 →  $\mathrm{pass}^8$ =0.70 能上线；全 0.7 →  $\mathrm{pass}^8$ =0.057 不能。**flaky rate 才是可部署性指标。** 报之前先做方差归因。

**污染三形态**：任务记忆（可改写）/ **环境记忆（改不掉）** / 运行时泄漏（环境卫生）。防御：程序生成 + 私有 test 只返聚合分 + 季度滚动 30% + 时间切分。不承诺零污染。

**成本**：500×8×30 步 ≈ 10 亿 input token。分层 CI + 自适应 $k$（只对 $p\in[0.2,0.8]$ 追加）+ prefix cache。序贯早停会低估 flaky，只用于快筛。

**必背句**：
- 只看结果的评测在现实中不存在——总会叠效率项，而那个组合会把最高分发给绕过合规的 agent。
- 过程分不是给成功的 agent 加分，是给"看起来成功"的 agent 减分。
- 报  $\mathrm{pass}^k$  之前先证明这个方差是模型的方差，不是我 harness 的方差。
- verifier 是 benchmark 里唯一没人评测的组件。
- 我引用公开 benchmark 是为了借它的失败模式，不是借它的分数。
