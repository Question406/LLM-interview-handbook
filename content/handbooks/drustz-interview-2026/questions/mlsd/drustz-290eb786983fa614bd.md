## 7. 分层与切片：不要给总分 ⭐⭐⭐

### 7.1 切片维度

| 维度 | 取值举例 | 为什么必须单独看 |
|---|---|---|
| **能力域** | 数学、代码、知识问答、创意写作、改写编辑、推理规划、多轮跟随、工具调用、闲聊/情感 | 不同域的退化互相独立；RLHF 常见"写作变好、数学变差" |
| **语言** | 英 / 中 / 西 / 阿 / 低资源 | judge 质量、tokenizer 效率、训练数据量都不同 |
| **难度** | 用 item discrimination 分档（§10.4） | 平均分掩盖"简单题满分、难题崩溃" |
| **安全类别** | 自伤、暴力、性、隐私、诈骗、仇恨、未成年人、医疗/法律建议、CBRN | 安全是 gate 不是 score（§11） |
| **输入长度 / 上下文占用** | <1k / 1k–32k / >32k tokens | 长上下文的失败模式完全不同（中间遗忘） |
| **对话轮次** | 单轮 / 2–5 轮 / >5 轮 | 多轮的指令遵循衰减是独立故障模式 |
| **用户段** | 新用户 / 老用户 / 免费 / 付费 / 开发者 API | 分布差异极大，付费用户的问题更长更专业 |

### 7.2 报告规则（可以直接背）

1. **每个切片报 n、point estimate、95% CI 三件套。** `n < 100` 的切片只报区间，不报点值，且在图上标灰——不给假精度。
2. **同时报两个总分**：按真实流量加权的"产品分"和等权的"能力分"。两者背离说明流量集中在容易的部分，产品分虚高。
3. **报最差切片（min-slice）**，不只报平均。用户体验的是自己那个切片，不是平均。
4. **切片 gate 分两类**：`primary` 可以升可以微跌，`guardrail` 不得跌超过阈值（对应 [08 §4](?book=drustz-interview-2026&section=mlsd&question=drustz-f15a9e25a058981436)）。
5. **多重比较要处理**：20 个切片 × α=0.05 → 期望 1 个假阳性。发现性分析用 Benjamini–Hochberg 控 FDR；guardrail 不用 p 值，用固定阈值 + 非劣性检验（§8）。

### 7.3 切片的样本量成本

一个可以在白板上算的例子（面试里报这种算术很加分）：

```text
8 个能力域 × 6 种语言 × 3 个难度 = 144 个切片
每切片最少 100 条            → 14,400 条 prompt
每条 prompt 跑 2 个模型      → 28,800 次模型生成（14,400 对答案）
每对答案双向各判一次          → 28,800 次 judge 调用
judge 单价 ~$0.02            → ~$580 / 次完整 gate
再加一个跨家族 judge 复核     → 翻倍到 ~$1,150
若全部人工（$2/对）          → ~$28,800 且要 3–5 天
```



结论直接推出 §10 的sampling策略：**judge 全量跑得起，人工只能覆盖 5–10%，所以人工必须花在"最能改变结论"的样本上。**
