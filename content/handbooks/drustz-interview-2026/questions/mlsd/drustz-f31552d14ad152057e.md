## 18. 候选人的对位素材：哪段引用哪个经历 ⭐⭐⭐

| 章节 | 引用什么 | 怎么说（一句话话术） |
|---|---|---|
| §5.2 多阶段合成流水线 | **Reflection mid-training，为 RL 合成与筛选 math/STEM 数据**；从开源集 + 原始文本（教材/论坛/Stack Exchange/竞赛题）出发的多阶段 LLM 流水线 | 「我现在的主责就是这条线。从原始文本到可训练 prompt 我们分了 question rewriting、answer rewriting、QA 转换几级，每级单独报通过率和成本。」 |
| §5.3 质量特征 | **自包含 / 无矛盾信息 / 假设是否给足** | 「这三条是我实际在打的标。『无矛盾』那条是我加的，因为矛盾题在 RL 里会被难度筛选主动捞出来——它的 pass rate 恰好落在保留带里。」 |
| §6 可验证化 / QA 转换 | 把不可验证题转成可验证的 | 「我们有一级专门做 QA 转换。踩过的坑是转换会改变难度，转完必须重新探测，不能沿用原题的标签。」 |
| §6.2 路径 D / §9.3 judge | **Anthropic take-home（医疗，可公开讲）**：ROUGE 预测「不安全回复」AUROC 0.569 vs claim 级 grounding grader 0.844，CI 不重叠；137 对扰动测试套件按扰动类型分层报检出率 | 「我有一组对照数据支持『缩小 judge 作用域』这个判断——整体相似度指标 AUROC 只有 0.569，拆成 claim 级到 0.844，confidence interval不重叠。」 |
| §7.2 两阶段探测 | ⭐**16 条探测 → 丢全对全错 → 128 条正式，约 12% 算力用于筛选** | 这是全篇最强的锚点，务必主动讲、并现场把误杀率和成本占比算给对方看 |
| §7.3 DAPO | 「这个思想和 DAPO 的 dynamic sampling 一致」 | 主动点名论文，然后**讲清离线 vs 在线的成本结构差异**——只说「和 DAPO 一样」不够，讲差异才显功力 |
| §9.3 judge 一致性 | **LRM-as-judge 同一标准在不同题目上判得不一致**（真实观察） | 「我遇到的具体形态是：同样是『解法有一步跳跃』，judge 在 A 题判过、B 题判不过。我的解释是 judge 的能力预算被题目难度占用了。」 |
| §10 reward hacking | **手动检查 trace 发现格式化推理 / 失控推理 / 错误推理 / reward hacking** | 「这四种我都在 trace 里实际见过。我讲一下是怎么看见的——」（然后展开 §10.2 的分层抽样协议） |
| §10.1 过程 vs 结果奖励 | **decagon_finetune L5 实测**：153 条轨迹，final-only reward 对合规/违规完全无法区分（都是 1.000）；加效率惩罚后跳步骤反而胜出（0.800 vs 0.750） | 「结果 reward 的盲区不是理论担忧，我构造过一个能量出来的对照。」 |
| §13.2 基础设施 | ⭐**共享 GPU 池、抢占常态、自建 pause/resume、动态申领让出、TCP 式 AIMD 并发调节** | 第二强的锚点。**一定要讲那两个调出来的细节**（失败窗口率 vs 单次退避；并发下限），细节才是证据 |
| §12 迭代闭环 | Meta 的**内部数据分析 agent**（多 agent sampling表格 → sandbox 写代码 → 综合假设供下一轮线上实验） | 「这个『观察 → 归类 → 回改 pipeline』的闭环我在 Meta 做数据分析 agent 时也是同一个形状，只是那边的下一轮是线上实验。」 |
| §11 配比 / 领先指标 | Meta **Instagram Reels / Facebook Feed 推荐建模** | 只在被问到「多目标配比/在线实验设计」时轻带一句，**不要展开**——推荐系统的配比逻辑和这里不是一回事，讲多了反而稀释 |
| 附加深度（被问算法细节时） | **手写实现的 reverse-KL on-policy distillation**（[decagon_finetune L6](https://github.com/DrustZ/ai_interview_prep_2026/blob/04316c111d0e4b75ca2ab8de0e6b42379727946e/projects/decagon_finetune/levels/level6_onpolicy_distill/)）：reverse KL = mode-seeking，容量受限的学生锁定单峰（σ=1.20 恰好等于教师峰宽），forward KL 坐到两峰之间的低谷 | 追问「distillation和 RL 怎么选」时用。**助记**：期望的下标里是谁谁就是sampling者，on-policy = 学生sampling = reverse |
