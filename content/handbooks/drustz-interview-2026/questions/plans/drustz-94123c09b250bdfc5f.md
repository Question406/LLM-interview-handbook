## Level 3：代码实现

你要能在 35–75 分钟内写出简化版：

- LRU / LFU
- Trie tokenizer
- Normalize path
- Flatten / Unflatten
- Dynamic batch scheduler
- Radix cache
- Versioned DB / nested transaction
- Durable KV cache
- Multithread sort
- Task scheduler
- File dedup / web crawler
- Stack trace parser
