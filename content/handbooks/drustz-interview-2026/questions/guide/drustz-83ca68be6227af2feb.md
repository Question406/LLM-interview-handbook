## 建议阅读顺序

1. 近期面试先看 OpenAI / Anthropic 题库，以及公司 Coding 与手写训练。
2. Agent 面试接着看 Core、Gaps、Benchmarks，再做 Interview Questions & Solutions。
3. ML / Data 面试看 ML System Design、Robotics 和 Labs。
4. Deep-ML 用来补 tensor、matrix、optimization 和经典 ML coding。
