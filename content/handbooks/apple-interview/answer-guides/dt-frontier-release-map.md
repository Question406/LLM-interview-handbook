## 可以这样回答

发版表格混合多种能力与评价协议。

2026 年闭源模型的发布主表主要报科学推理、仓库修复、终端操作、浏览、桌面操作、long context 和 multimodal，MMLU、HumanEval 已经不是重点。比分数前先核对思考预算、工具、尝试次数、运行框架、子集和报分方。evaluation set 的名字也不能当成 training set 的名字。
