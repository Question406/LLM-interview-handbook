## 可以这样回答

代码改名改格式后仍可能近克隆。

先规范化源码，切成 k-gram 算哈希，每个窗口只留最小的哈希当指纹，再用 Jaccard 比较指纹集合。许可证头和 import 块要先剥掉，否则大量无关的 Python 文件也会显得相似。
