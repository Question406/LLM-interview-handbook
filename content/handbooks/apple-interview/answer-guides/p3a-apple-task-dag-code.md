## 可以这样回答

任务有依赖，执行失败会影响后继。

用任务 ID 保存函数和依赖，用入度与后继表做拓扑执行。一个任务只在全部前驱完成后计算，依赖结果按声明顺序传入；共享上游任务每次运行只执行一次，不能用递归重复计算整棵依赖树。

测试还要满足这个条件：正常 DAG、失败依赖、环和重复运行都验证。
