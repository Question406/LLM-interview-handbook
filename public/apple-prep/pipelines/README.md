# 三条 Pipeline 的数据契约示例

这些JSONL由人工构造，仅展示记录粒度、失败类型和训练视图。没有实际截图、程序或环境执行；example://引用、hash、模型名和标签不是采集产物。eligible_views表示待审计的潜在用途，不表示已经具备训练资格。不得据此报数据规模或实验结果。

- skill_harness.jsonl：同一初态下，未加载去重skill的失败与正确加载候选。
- code_verifier.jsonl：已测通过、复杂度失败与未知样例，演示三态标签。
- mm_tool_use.jsonl：金额正确、误读小计、动作前截图失配的隔离记录。

完整trajectory还应保存允许的观察与工具回包、时间戳、版本、重置证明、策略采样配置、权限和过程审核。页面的三张Pipeline卡给出处理步骤与验收条件。
